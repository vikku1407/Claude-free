Built so nothing stands between you and the file

Four design rules this repo follows — and the reason a plain repo can still feel good to use.

⌘

Clone → done. No setup theatre

One static page, one CSS file, one JS file. No npm install, no node_modules the size of a small OS, no build step to break at 2 AM. Open it on a phone, a school laptop, a locked-down work machine — it renders.

⚖️

Actually free

MIT licensed and free as in "use it in your product", not free as in "free tier up to 50 requests".

🔒

Zero tracking

No analytics, no cookies, no fingerprinting. The theme toggle is the only thing remembered, and it lives in your own browser.

✦

Accessible by default, not as a patch

Semantic landmarks, visible focus rings, AA+ contrast in both themes, respects prefers-reduced-motion, and every control is reachable with a keyboard alone. Scales from 320 px to ultrawide without a horizontal scroll.

Three commands, then it's yours

No install script, no secrets to paste. Any static host works: GitHub Pages, Netlify, Cloudflare Pages, or a folder on your own machine.

Questions people actually ask

Is it really free, or is there a catch?

Free. MIT licensed — you can use it commercially, modify it, redistribute it, close it. There's no account to create and no feature locked behind a card. The only thing I'd like is a star if it saved you time.

Why the name "Claude-free"?

It means free, in the spirit of things built around Claude — an unofficial, community project. It is not affiliated with or endorsed by Anthropic, and nothing here needs their approval to fork.

Do I need to install anything?

No. It's static HTML/CSS/JS. Double-click index.html and it works. Python's built-in server is only for a nicer local dev experience with live reload-ish convenience.

Can I contribute my own prompts or tools?

Yes — open an issue first so we don't duplicate work, then a pull request with one focused change. Keep files small, dependency-free, and include a line on what problem it solves.

Will this stay maintained?

It's a one-person repo, so I won't promise SLAs. What I do promise: it stays MIT, it stays free, and nothing will be quietly replaced by a signup form.
